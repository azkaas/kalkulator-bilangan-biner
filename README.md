# 🔢 Kalkulator Konversi Bilangan

Aplikasi web sederhana berbasis Python dan Streamlit untuk melakukan konversi:

- Bilangan Biner → Desimal
- Bilangan Desimal → Biner

## 🚀 Demo Aplikasi

Link Streamlit:
https://namalinkaplikasi.streamlit.app

## 🛠️ Teknologi yang Digunakan

- Python
- Streamlit
- GitHub

## ▶️ Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/username/kalkulator-biner.git
```

### 2. Masuk ke Folder Project

```bash
cd kalkulator-biner
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Jalankan Streamlit

```bash
streamlit run app.py
```

## 📂 Struktur Folder

```text
kalkulator-biner/
│
├── app.py
├── requirements.txt
└── README.md
```

## ✨ Fitur

✅ Konversi biner ke desimal  
✅ Konversi desimal ke biner  
✅ Validasi input biner
